# 派对游戏盒

一个聚会小游戏集合，包含谁是卧底、数字炸弹、猜词助手三款游戏。传手机就能玩，点开即玩。

## 功能特性

### 三款游戏
- **谁是卧底** - 隐藏身份，互飙演技，支持3-10人
- **数字炸弹** - 紧张刺激，轮流猜数字，猜中就炸
- **猜词助手** - 你比我猜/口头描述/你画我猜，海量词库

### 完美适配
- 移动端优先设计，适配各种手机屏幕
- 支持振动反馈、屏幕常亮
- 流畅的动画和交互体验

### 其他功能
- 战绩记录（本地存储）
- 7大词库分类，500+词汇
- 自定义游戏设置

## 快速部署

### 部署到 GitHub Pages

1. 在 GitHub 上创建一个新仓库（Public 公开仓库）
2. 将本项目代码推送到仓库
3. 进入仓库 Settings → Pages
4. Source 选择 "Deploy from a branch"
5. Branch 选择 `main` / `(root)`
6. 点击 Save
7. 等待 1-2 分钟，页面会显示你的网站地址

也可以部署到任何静态网站托管服务（Vercel、Netlify、Cloudflare Pages 等）。

### 开始使用

访问你的网站地址，选择一个游戏，设置好人数和选项，就能开始玩了。

## 使用说明

### 谁是卧底
1. 选择玩家数量和词库分类
2. 每人轮流查看自己的词语（确保别人看不到屏幕）
3. 全部查看完毕后，进入描述阶段
4. 每人轮流用一句话描述自己的词语
5. 描述完毕后投票选出卧底
6. 得票最多的人出局，揭晓身份
7. 重复直到游戏结束
   - 所有卧底出局 → 平民胜利
   - 平民人数 ≤ 卧底人数 → 卧底胜利

### 数字炸弹
1. 选择数字范围和玩家数量
2. 系统随机设定一个炸弹数字
3. 玩家轮流猜数字
4. 每次猜测后，安全范围会缩小
5. 猜中炸弹数字的人输！

### 猜词助手
1. 选择模式（你比我猜/口头描述/你画我猜）
2. 选择词库分类和每轮时长
3. 屏幕显示词语，比划者表演/描述，队友猜词
4. 猜对了点"猜中了"，不会点"跳过"
5. 时间结束后统计成绩

## 常见问题

**Q: 最多支持多少人同时游戏？**
A: 建议不超过 10 人，体验最佳。

**Q: 能自定义词库吗？**
A: 可以，直接修改 `js/wordbank.js` 文件中的词汇即可。

**Q: 需要联网吗？**
A: 不需要，所有游戏都是单机模式，传手机轮流操作即可。
